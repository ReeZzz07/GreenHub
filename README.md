# GreenHub

PWA-маркетплейс для C2C и B2C торговли растениями, саженцами, семенами и сопутствующими товарами.

## 📖 О проекте

GreenHub — это прогрессивное веб-приложение (PWA), которое соединяет продавцов и покупателей растений в России. Платформа выступает информационным посредником, предоставляя инструменты для размещения объявлений, коммуникации и безопасных платежей через внешние платежные системы.

**Ключевые особенности:**
- 🌱 AI-распознавание растений по фото
- ✨ Автоматическая генерация описаний с помощью LLM
- 🔒 Вотермарки на всех изображениях для защиты контента
- 💬 Встроенный чат между покупателями и продавцами
- 📱 PWA с оффлайн-режимом для просмотра каталога
- 🛡️ Модерация объявлений и фитосанитарный контроль

## 🚧 Статус проекта

Сейчас реализован только фронтенд-каркас (папка `frontend/`) на моковых данных, без бэкенда:

- ✅ Next.js-приложение с роутами `/`, `/catalog`, `/recognize`, `/cart`, `/profile`, `/plant/[id]`
- ✅ UI-компоненты, контексты корзины/авторизации (на `localStorage`), моковый каталог растений
- ❌ Backend (NestJS), база данных, очереди, S3 — не реализованы
- ❌ Интеграции с Plant.id, LLM, ЮKassa/Robokassa — не подключены

Разделы ниже описывают **целевую архитектуру MVP** согласно [TZ.md](./TZ.md), а не всё, что уже работает.

## 🛠 Технологический стек

### Frontend
- **Next.js** + TypeScript — SSR/SSG рендеринг
- **Tailwind CSS** — стилизация
- **PWA** — Service Workers для оффлайн-работы

### Backend
- **NestJS** + TypeScript — модульная архитектура API
- **Prisma/TypeORM** — ORM для работы с БД
- **BullMQ + Redis** — очереди задач для фоновой обработки
- **Sharp** — обработка изображений (сжатие, вотермарки)

### База данных и кэширование
- **PostgreSQL** — основное хранилище данных
- **Redis** — кэширование, сессии, очереди

### Инфраструктура
- **Docker + Docker Compose** — контейнеризация
- **Yandex Object Storage (S3)** — хранение медиафайлов
- **VPS (Ubuntu)** — хостинг backend и БД
- **Vercel / Nginx** — хостинг frontend
- **Prometheus + Grafana** — мониторинг
- **Winston** — логирование

### Внешние сервисы
- **Plant.id API** — распознавание растений
- **Qwen API (или аналоги)** — генерация описаний
- **ЮKassa / Robokassa** — платежные ссылки

## 🚀 Быстрый старт

На данный момент в репозитории реализован только фронтенд — инструкции ниже касаются только его.
Требования к бэкенду (Docker, PostgreSQL, Redis, Yandex Object Storage) актуальны только после его реализации.

### Предварительные требования
- Node.js 18+

### Установка

1. **Клонирование репозитория**
```bash
git clone https://github.com/ReeZzz07/GreenHub.git
cd GreenHub/frontend
```

2. **Установка зависимостей**
```bash
npm install
```

3. **Запуск в режиме разработки**
```bash
npm run dev
```

Приложение будет доступно на [http://localhost:3000](http://localhost:3000).

### Другие команды
```bash
npm run build   # Production-сборка
npm run start   # Запуск production-сборки
npm run lint    # Проверка линтером
```

## 🔑 Основные возможности MVP

### Для покупателей
- Просмотр каталога растений с фильтрами
- Поиск по категориям, тегам и атрибутам
- Добавление товаров в избранное
- Чат с продавцами
- Оплата через защищенные платежные ссылки

### Для продавцов
- Создание объявлений с AI-помощником
- Автоматическое распознавание растений по фото
- Генерация продающих описаний через LLM
- Управление объявлениями и статусами
- Базовая аналитика (просмотры, избранное, клики)
- Подписка для питомников (массовое управление)

### Для модераторов
- Проверка новых объявлений (SLA 24 часа)
- Верификация фитосанитарных сертификатов
- Модерация чатов и контента
- Шаблоны быстрых ответов для отклонения

### Для администраторов
- CRUD категорий и подкатегорий
- Управление ролями пользователей
- Настройка тарифов подписок
- Полный доступ ко всем данным платформы
